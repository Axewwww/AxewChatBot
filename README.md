# Axew AI Chatbot 🤖

Axew AI is an AI-powered chatbot website designed to provide natural conversations through a personalized AI assistant.

## Features
- AI-powered conversations
- Custom chatbot interface
- Python-based application
- Personalized assistant experience

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Supabase (where implemented)

## Project Status
Currently in development.

## Getting Started
1. Clone or download this repository.
2. Install the required Python dependencies.
3. Configure your API credentials securely using environment variables or Streamlit secrets.
4. Run the application with Streamlit.

```bash
streamlit run app.py
```
